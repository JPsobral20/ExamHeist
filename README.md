# Exam Heist

**Exam Heist** is a 2D stealth platformer developed using **Unity and C#**. Play as a student attempting to steal an exam from a professor's office by sneaking through a guarded building, avoiding security systems, and solving puzzles along the way.

## 🎮 Gameplay

The objective is to infiltrate the building, retrieve the exam, and escape without being detected.

Key gameplay mechanics include:

- **Stealth:** Avoid guards and security cameras while navigating the building.
- **Hiding:** Use closets to hide from enemies and avoid triggering the alarm.
- **Exploration:** Collect keys to unlock doors and access restricted areas.
- **Puzzle Solving:** Find a pen and documents to uncover the password to the professor's computer.
- **Escape:** Successfully leave the building after retrieving the exam.

## 🛠️ Technologies

- **Game Engine:** Unity
- **Programming Language:** C#
